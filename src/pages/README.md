# Pages Directory

Contiene los contenedores principales de la aplicación, organizados por módulos funcionales.

## Módulos
* `Landing/`: Página de marketing pública.
* `Login/` & `Register/`: Módulos de autenticación y onboarding.
* `Dashboard/`: Resumen operativo y métricas.
* `Vehicles/`, `Drivers/`, `Routes/`, `Maintenance/`: Módulos de gestión core (Placeholders preparados para implementación).
