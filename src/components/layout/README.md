# Layout Components

Componentes responsables de la estructura y navegación global de la aplicación.

## Contenido
* `Sidebar.jsx`: Navegación lateral con soporte para colapsado y modo móvil.
* `Navbar.jsx`: Barra superior con títulos dinámicos y buscador.
* `UserMenu.jsx`: Dropdown para gestión de perfil y sesión.
* `NotificationButton.jsx`: Centro de alertas operativas.
