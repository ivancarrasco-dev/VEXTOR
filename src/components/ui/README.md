# UI Components

Este directorio contiene componentes atómicos y reutilizables de la interfaz de usuario de Vextor.

## Principios
* **Consistencia:** Todos los componentes siguen el sistema de diseño "Emerald & Slate".
* **Accesibilidad:** Uso de atributos ARIA y soporte para navegación por teclado.
* **Componibilidad:** Diseñados para ser combinados y extender su funcionalidad mediante props.

## Componentes Clave
* `Button.jsx`: Botón principal con variantes (primary, outline, ghost) y estados de carga.
* `Input.jsx`: Campo de entrada con soporte para iconos, etiquetas y mensajes de error.
* `Checkbox.jsx`: Control de selección con estilo personalizado.
* `Logo.jsx`: Centraliza la marca Vextor, permitiendo alternar entre logo completo e isotipo.
