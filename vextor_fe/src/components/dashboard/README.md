# Dashboard Components

Componentes especializados para la visualización de datos y acciones dentro del panel operativo.

## Contenido
* `StatsCard.jsx`: Tarjetas de métricas con indicadores de tendencia (subida/bajada).
* `QuickActionCard.jsx`: Accesos rápidos con iconos y descripciones para mejorar la velocidad operativa.
* `RecentActivity.jsx` (Integrado en Dashboard): Lista de eventos recientes con codificación de estados.
