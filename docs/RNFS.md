# Requisitos No Funcionales – VEXTOR

- **RNF-001 (Rendimiento):** Máximo 3 segundos de carga bajo condiciones normales.
- **RNF-002 (Rendimiento):** Soportar al menos 100 usuarios simultáneos.
- **RNF-003 (Seguridad):** Contraseñas almacenadas con mecanismos de cifrado seguro.
- **RNF-004 (Seguridad):** Controlar el acceso según el rol del usuario.
- **RNF-005 (Seguridad):** Toda transmisión de información mediante HTTPS.
- **RNF-006 (Usabilidad):** Interfaz intuitiva y comprensible.
- **RNF-007 (Usabilidad):** Compatible con dispositivos móviles y computadores.
- **RNF-008 (Disponibilidad):** Disponibilidad mínima del 95%.
- **RNF-009 (Mantenibilidad):** Permitir actualizaciones sin afectar integridad de datos.
- **RNF-010 (Escalabilidad):** Permitir nuevos módulos sin afectar el funcionamiento actual.
